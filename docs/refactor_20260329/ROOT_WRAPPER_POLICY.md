# 루트 호환 래퍼 유지 정책

## 목적

- 디렉토리 재배치 후에도 기존 실행 명령과 import 경로를 즉시 깨지지 않게 유지

## 현재 상태

- 루트에는 `run/`, `settings/`, `reporting/`, `tools/` 로 이동한 파일에 대한 호환 래퍼가 남아 있음
- 새 구현은 하위 디렉토리에 두고, 루트는 최소 호환 레이어로만 사용

## 규칙

- 신규 코드는 루트 래퍼를 직접 import 하지 않는다
- 신규 문서와 신규 명령 예시는 모두 하위 디렉토리 기준으로 작성한다
- `bot_manager.py` 는 `run/` 기준 경로를 사용한다
